## 2. What Prism is (enough to work on it)

Desktop app. The user describes a job; Groq plans stages; the engine drives
the user's own AI tools (ChatGPT, Claude, Perplexity, Apollo, Canva, …) in
the user's own Chrome (undetected-chromedriver, profile at
`~/.prism/chrome_profile`); results land in History/Artifacts. Add-ons with
their own screens: Email automation (inbox), BOQ, BOM, Gerber, **STEP (new,
this session)**, Email, Reel/Studio/Motion (local video renderers).
Confidential design files (Gerber, DXF, STEP) are measured locally; only
numbers go to an AI. `CHANGES.md` (top of file) is the authoritative,
newest-first log of every change, written for a future maintainer — read
Rounds 11–15 there for the "why" of everything below.

Run the suite: `python3 -m pytest tests -q -p no:cacheprovider` (≈1,700
tests, ~2 min). Two known flakes unrelated to this work:
`tests/test_inquiry_screen.py::TheScreenStaysInStepWithTheStore::test_refresh_picks_up_a_register_written_after_load`
(reads Hitarth's real inquiry register) and an occasional conftest teardown
error when a licence-refresh thread reaches the real server mid-suite
(`tests/test_worklist.py` passes alone).
