2. Detailed Findings & Defect Log

Test 1: General Task Compose & Draft Autosave

✓ PASSED: Draft Autosave Functionality
Composed prompt text persisted reliably when switching between rail tabs and returning to "+ New task".
⚠ BUG-01: Drag and Drop Document Not Supported (No Drop Zone)
• Expected: Dragging a document from Windows Explorer into the task card attaches the file.
• Actual: Hovering the dragged file displays the Windows prohibition cursor (⊘). No drop zone exists in code.
• Workaround: Users must click the manual "Add file" button.

Test 2: Context Inspector Panel (Alt + C)

✓ PASSED: 'Behind the Scenes' Prompt Breakdown
Expanded cleanly after "Make a plan", rendering "01 YOU SAID", "02 PRISM'S TASK BRIEF", and "03 ENGINEERED PER-TOOL PROMPTS".
⚠ BUG-02: Keyboard Shortcut 'Alt + C' Unresponsive
• Expected: Pressing Alt + C on the keyboard toggles the right-hand Context Inspector panel.
• Actual: Alt + C produces no action. Shortcut is unmapped in main_window.py.
• Workaround: Users must click the small collapsed chevron icon in the top-right corner.

Test 3: Running Screen Controls (Stop & Retry)

✓ PASSED: Plan Generation & Pipeline Initiation
"Make a plan" accurately parsed the task into sequential stages and "Start the work" initiated execution.
⚠ BUG-03: Stop Button Does Not Halt Immediately (Hangs for 5m 52s)
• Expected: Clicking the red Stop button halts execution immediately.
• Actual: Clicking Stop disabled the button and changed label to "Stopping...", but the background Perplexity step ran for 5m 52s before concluding.
• Root Cause: Engine does not forcefully abort in-flight browser/network requests.
⚠ BUG-04: 'View Partial Results' Toast Missing & Misleading Dialog
• Expected: Halting the run displays a toast notification with the message "View partial results".
• Actual: No toast is shown. Instead, a completion modal dialog falsely claims "✓ Prism finished the work", even though the user deliberately stopped the run and Step 2 was cancelled.

Test 4: Run History Screen

✓ PASSED: Past Run Record Rendering & Follow-up Launch
Past runs re-render with step-by-step descriptions, prompt queries, and outputs. Clicking "Follow up" launches continuation.
⚠ BUG-05 (Critical): Stopped Tasks Falsely Badged as '[ ✓ COMPLETED ]'
• Expected: Tasks cancelled/stopped by the user should be badged as 'Stopped' or 'Cancelled'.
• Actual: The History list marks stopped runs (e.g. Batman and Space tasks) with green [ ✓ COMPLETED ] badges, despite no deliverables being captured.
⚠ BUG-06: Detail Drawer Missing (Replaced by Modal Dialog)
• Expected: Clicking a past run slides out a Detail Drawer from the right.
• Actual: PRISM launches a blocking modal dialog (Run history - Prism).
⚠ BUG-07: Action Button Label Discrepancy
• Expected: Button labeled "Continue this run".
• Actual: Button is labeled ↑ Follow up (and is hidden on runs where no content was captured).

Test 5: Artifacts Screen

✓ PASSED: Organization, Built-in Preview & Windows Explorer Launch
Each past run has its own dedicated folder. Built-in media preview plays video reels directly in-app. Clicking "Open the folder" cleanly launches Windows File Explorer at the exact artifact directory.

Test 6: Favorites Shelf

✓ PASSED: Add Favorite & Quick-Attach to Task
Adding a PC folder via the "+" button listed it under Favourites. Double-clicking the favorite attached the folder to the task composer (showing "Already attached."). Deletion via the rail's trash icon successfully removed it.
⚠ BUG-08: Right-Click Context Menu & Inline 'x' Missing on Favorites
• Expected: Right-clicking a favorite item or clicking an inline 'x' removes it.
• Actual: No right-click context menu and no inline 'x' exist. Removal requires selecting the row and clicking the header trash icon (🗑).
