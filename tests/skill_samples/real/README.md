# Real replies, as Prism captured them

Excerpts of replies from the owner's own Prism runs (`~/.prism/runs`), saved
exactly as the engine captured them from the chat page, so the skill checkers
are tested against what they will actually read. Client names and work-order
numbers are replaced; long replies are cut to their head and tail, joined by a
line holding a single `…`.

| File | What it is |
|---|---|
| research-perplexity-*.txt | Perplexity research replies. Citations arrive as a bare site name on the line under a claim. |
| boq-bom-writeup-chatgpt.txt | A ChatGPT BOQ/BOM write-up. Table rows arrive as cells joined by spaces; bearings are quantified in inches. |
| document-chatgpt.txt | A ChatGPT "make a DOCX document" reply written inline, with image and logo placeholders left in. |
| document-claude-built-docx.txt | Claude building the DOCX itself: the chat shows a file card, not the document. |
| document-chatgpt-with-skill.txt | Live run, ChatGPT with the document skill: a dated cover block above PAGE 1. |
| deck-claude-built-pptx.txt | Live run, Claude asked for a deck: it built the .pptx in its sandbox and the chat shows only the build log. |

Captured 2026-09-11. Regenerate only from real runs; never hand-edit these to make a test pass.
